# CEBICOR AI Studio V1

Primera versión funcional sin API externa.

## Funciones
- Generador de campaña semanal
- Instagram, Reel, LinkedIn, Email, WhatsApp y Landing
- Descarga en ZIP desde el navegador
- Guardado local de campañas
- Calendario, tendencias y biblioteca

## Publicación en Vercel
Sube `index.html`, `cebicor-logo.png` y `vercel.json` a la raíz del repositorio.
Vercel publicará la actualización automáticamente.
